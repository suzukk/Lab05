# Лабораторийн ажил №5 — API Testing

## Оюутны мэдээлэл

- **Оюутны нэр:** С.Тэргэл
- **Оюутны код:** B232270011
- **Үйлдлийн систем:** Arch Linux
- **Node.js:** v26.8.1
- **Newman:** 6.2.2

## 1. Лабораторийн ажлын зорилго

Энэхүү лабораторийн ажлын зорилго нь REST API-ийн ажиллагааг Postman Collection болон Newman ашиглан автоматжуулсан байдлаар шалгах юм. Туршилтаар оюутны хичээлд бүртгүүлэх үйлдлийн амжилттай, алдаатай болон хязгаарын нөхцөлүүдийг шалгасан.

## 2. Ашигласан технологи

- Node.js — API сервер ажиллуулах
- Postman Collection — API хүсэлт болон тестийн нөхцөлүүдийг тодорхойлох
- Newman — Collection-ийг командын мөрөөс ажиллуулах
- Git, GitHub — Хувилбарын удирдлага

## 3. Тестийн хамрах хүрээ

| № | Тестийн кейс | Хүлээгдэх үр дүн |
|---|---|---|
| 1 | Идэвхтэй оюутан үүсгэх | HTTP 200 |
| 2 | Хичээл үүсгэх | HTTP 200 |
| 3 | Хичээлд амжилттай бүртгүүлэх | HTTP 201 |
| 4 | Байхгүй оюутнаар бүртгүүлэх | `ERROR_NO_STUDENT` |
| 5 | Идэвхгүй оюутнаар бүртгүүлэх | `ERROR_INACTIVE_STUDENT` |
| 6 | Байхгүй хичээлд бүртгүүлэх | `ERROR_NO_COURSE` |
| 7 | Урьдчилсан нөхцөл хангаагүй үед бүртгүүлэх | `ERROR_PREREQUISITES` |
| 8 | `studentID` талбар орхих | HTTP 400 |
| 9 | `courseID` талбар орхих | HTTP 400 |
| 10 | Урьдчилсан нөхцөлгүй хичээлд бүртгүүлэх | HTTP 201 |

## 4. Equivalence Partitioning

Оролтын өгөгдлийг ижил үр дүн хүлээгдэж буй бүлгүүдэд ангилсан.

| Оролтын бүлэг | Жишээ | Хүлээгдэх үр дүн |
|---|---|---|
| Идэвхтэй, хүчинтэй оюутан | `B231234567` | Бүртгэл амжилттай |
| Байхгүй оюутан | Бүртгэлгүй ID | `ERROR_NO_STUDENT` |
| Идэвхгүй оюутан | `B231111111` | `ERROR_INACTIVE_STUDENT` |
| Хичээл олдохгүй | Бүртгэлгүй course ID | `ERROR_NO_COURSE` |
| Урьдчилсан нөхцөл хангаагүй | `CS201` судлаагүй | `ERROR_PREREQUISITES` |
| Шаардлагатай талбар дутуу | `studentID` эсвэл `courseID` байхгүй | HTTP 400 |

## 5. Boundary Value Analysis

Хичээлд бүртгүүлэх үеийн урьдчилсан нөхцөлийн шалгалтад дараах хил заагийн нөхцөлийг авч үзсэн.

| Нөхцөл | Тестийн утга | Хүлээгдэх үр дүн |
|---|---|---|
| Урьдчилсан нөхцөл байхгүй | `CS400` | Бүртгэл амжилттай |
| Урьдчилсан нөхцөл шаардлагатай боловч хангаагүй | `CS313`, `CS201` судлаагүй | `ERROR_PREREQUISITES` |
| Урьдчилсан нөхцөл хангагдсан | `CS201` судалсан | Бүртгэл амжилттай |

## 6. Туршилтын үр дүн

### PASS — Амжилттай туршилт

Файл: `results/newman-pass.txt`

- Requests: 14
- Assertions: 19
- Failed assertions: 0
- Exit code: 0

Бүх assertion амжилттай биелсэн.

### FAIL — Алдаатай assertion

Файл: `results/newman-fail.txt`

Энэ туршилтад амжилттай бүртгүүлэх хүсэлтийн хүлээгдэж буй HTTP статусыг зориудаар `201` биш `200` болгон өөрчилсөн.

- Requests: 14
- Assertions: 19
- Failed assertions: 1
- Exit code: 1

API бодитоор HTTP 201 буцаасан тул зориудаар өөрчилсөн assertion унасан.

### DOWN — Сервер ажиллахгүй үеийн туршилт

Файл: `results/newmandown.txt`

API серверийг зогсоосны дараа Collection-ийг ажиллуулсан.

- Requests: 14
- Холболтын алдаа: 14
- Failed assertions: 19
- Exit code: 1
- Алдаа: `ECONNREFUSED 127.0.0.1:3000`

Сервер ажиллахгүй үед хүсэлтүүд холбогдож чадаагүй бөгөөд Newman алдааны код буцаасан.

## 7. Туршилт ажиллуулах

API серверийг нэг терминалд асаана:

```bash
node server.js
```

Өөр терминалд PASS туршилтыг ажиллуулна:

```bash
newman run lab05-collection.json \
  --env-var "baseUrl=http://localhost:3000" \
  -r cli
```

FAIL туршилт:

```bash
newman run lab05-collection-fail.json \
  --env-var "baseUrl=http://localhost:3000" \
  -r cli
```

DOWN туршилтыг хийхийн өмнө API серверийг зогсооно.

## 8. Дүгнэлт

Энэ лабораторийн ажлаар REST API-г Newman ашиглан автоматжуулсан байдлаар туршиж сурлаа. Амжилттай бүртгүүлэх болон алдаатай оролтын нөхцөлүүдийг шалгасан. Equivalence Partitioning аргаар оролтын өгөгдлийг хүчинтэй болон хүчин төгөлдөр бус бүлгүүдэд ангилсан. Boundary Value Analysis аргаар урьдчилсан нөхцөлтэй болон нөхцөлгүй хичээлийн бүртгэлийг шалгасан. PASS туршилтаар 19 assertion бүгд амжилттай биелсэн. FAIL туршилтад нэг assertion-ийг зориудаар буруу болгож, тестийн систем алдааг илрүүлж байгааг баталсан. DOWN туршилтаар сервер ажиллахгүй үед холболтын алдаа гарч байгааг шалгасан. Newman-ийн гаралтын үр дүнг тус тусад нь файлд хадгалсан. Энэхүү ажлаар API тестийн кейс боловсруулах, автоматжуулах болон үр дүнг тайлбарлах дадлага эзэмшлээ.
